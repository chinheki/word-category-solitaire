# 词语归位 · 生活联想

[打开试玩](https://chinheki.github.io/word-category-solitaire/)

提供10个混合生活主题关卡。每关6列、18类别、144张牌；开局桌面36张，抽牌堆108张。每关同时出现交通、饮食、居家、节日、旅行、自然、常见用语等10个领域，每个领域只占1–2个类别；另有3个熟悉的生活概念。105/126张词语牌来自这些日常领域，占83.3%。

所有新局完整洗牌后验证至少一条步数内的解法。支持整组移动、磁吸、中文单行缩字、外语长词换行、完成动画、提示、撤销和本地保存；没有登录、真实充值或广告。

中文词库已经过五轮修订，最近一轮的10组抽样获用户认可。升级后首次打开会清空此前版本的牌局、成绩和金币，从第1关及1800金币重新开始；此后的当前版本进度正常保存，刷新不会重新洗牌。

此仓库只保存浏览器运行文件、校验清单和GitHub Pages部署流程；开发源码、测试、对话、参考照片、登录和环境文件不在公开范围。Actions校验文件SHA256后部署site目录。本地开发验证与CI产物校验分别记录，不将CI部署称为真机验收。

分类目标尚未收进词语时保留金色类别牌原样，首张词语归入后切换为词语牌；类别名和进度仍在牌上方。

右上角可开启“词语解释”：悬停即时显示，点牌显示3秒；点空白处可提前关闭。说明简短且不直接给出类别标题。

点击右上角🌐可分别选择卡牌、界面、解释的语言：简体中文、英语、日语、法语、德语、西班牙语、希腊语。切换语言保留当前局与步数，偏好存于本机。外语译词由离线模型生成初稿，尚未经过母语者逐词审校；查看说明时会保留中文原词，便于对照。长词在卡片上可换行，最低字号9px，完整词形可在说明中查看。

本次中文修订新增的部分词尚无六语译文，选择外语时这些词会暂时显示中文。外语词表目前不适合作为可靠的语言学习材料，后续需逐词校对。

底部按钮下方的浮窗轮换显示已放入分类目标的词语及简短解释。归类后立即加入，撤销后同步移除；词语和解释分别采用所选语言。
